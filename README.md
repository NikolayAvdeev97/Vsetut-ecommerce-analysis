# Анализ данных e-commerce маркетплейса «ВсёТут»

## Описание проекта
В данном проекте проведена подготовка витрины данных для e-commerce платформы и решен ряд ad-hoc задач для продуктовой аналитики. Основная цель — сегментация пользователей, анализ региональных продаж и оценка динамики активности клиентской базы для разработки стратегии удержания.

## Стек технологий
* **Инструменты:** PostgreSQL, DBeaver
* **SQL-навыки:** Оконные функции (FIRST_VALUE, OVER, PARTITION BY), CTE (WITH), агрегатные функции, условная логика (CASE WHEN), работа с датами (DATE_TRUNC, EXTRACT), JOIN-соединения.

## Структура данных (Схема)
Анализ проводился на основе базы данных маркетплейса, состоящей из следующих таблиц:
* `ds_ecom.orders` — данные о заказах (статусы, даты оформления).
* `ds_ecom.users` — данные покупателей (регион проживания).
* `ds_ecom.order_items` — детализация товаров в заказах (цены, стоимость доставки).
* `ds_ecom.order_payments` — информация о транзакциях (типы оплат, рассрочки, промокоды).
* `ds_ecom.order_reviews` — отзывы и оценки покупателей.

## Ключевые выводы
1. **Сегментация:** 99,5% пользователей совершают только одну покупку. Для кратного роста выручки необходимо внедрение программ удержания и стимулирования повторных продаж.
2. **Лояльный сегмент:** Клиенты, совершившие от 3 заказов, демонстрируют наивысший средний чек в Москве и Санкт-Петербурге.
3. **Региональная специфика:** На Москву приходится 80% заказов платформы. При этом финансовые инструменты (рассрочка) более востребованы в регионах (до 55% заказов в СПб и Новосибирске).
4. **Когортная динамика (2023):** Наблюдается стабильный рост базы при удержании высокой оценки сервиса. Доля оплат прямыми денежными переводами стабильно держится на уровне 20%.
